# Farmland MP

A React-based website for Farmland MP, built with Vite, TypeScript, and Tailwind CSS. Features Netlify CMS for content management and Netlify functions for serverless backend.

## Features

- Modern React application with TypeScript
- Responsive design using Tailwind CSS
- Content management with Netlify CMS
- Serverless functions for form submissions
- Optimized build with Vite

## Development

### Prerequisites

- Node.js (version specified in .nvmrc)
- npm

### Installation

1. Clone the repository
2. Run `npm install`
3. Start development server: `npm run dev`

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

### CMS Development

- `npm run cms` - Start Netlify CMS proxy server
- `npm run cms:dev` - Run both dev server and CMS proxy concurrently

## Deployment

Deploy to Netlify with the included netlify.toml configuration.
